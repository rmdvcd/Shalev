Exportar al catálogo

Se crea un producto o servicio nuevo con una receta a partir de las partidas de materias primas. Se reutilizan insumos activos con el mismo nombre y unidad; los nuevos se crean sin existencias. No se actualizan precios de insumos existentes.

En escritorio, el producto exportado requiere existencias propias además de insumos para venderse. La ficha no se sincroniza como tal con las apps móviles. Una ficha solo puede exportarse una vez a cada tipo mientras el artículo creado permanezca activo.
