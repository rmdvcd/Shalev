# Capturas de pantalla de IShalev

Recorrido visual de **IShalev** (la contraparte iOS de Shalev, en `IShalev/`), en una carpeta de la raíz del repositorio. Se generaron como **maquetas fieles a la interfaz real** (SwiftUI, paleta Shalev, textos tomados de `IShalev/Sources/`) porque la sesión interactiva de [Appetize.io](https://appetize.io) se queda en la pantalla de licencia y no deja recorrer la app.

Las pantallas marcadas *(pendiente)* se completan en el siguiente lote (la generación de imágenes está limitada a 10 por turno). Al terminar, este índice se actualiza y se retira la marca.

> **Nota:** son ilustraciones generadas a partir del código y el sistema de diseño de IShalev, no capturas del simulador. Para las capturas reales hace falta un Mac con Xcode o una sesión interactiva de Appetize (o un iPhone físico).
